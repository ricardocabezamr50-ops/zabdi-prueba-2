# ZABDI Calzados (Expo React Native) – v2

## Cómo ejecutar
```bash
npm install
npm start
```
Escaneá el QR con **Expo Go** (o usá `npx expo start --tunnel`).

## Novedades v2
- Formulario de producto con validaciones y UI mejorada.
- Totales robustos en ventas, sin NaN.
- Stock nunca negativo.
- Tema visual con más contraste.
